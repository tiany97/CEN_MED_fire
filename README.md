# CEN_MED_fire
This is the code for paper "Historical changes in causal drivers of Mediterranean fire weather"
Use "FWI_96th_sub.ipynb" to calculate FWI index and produce Fig.1 and Figs. 3a-3h
Use "Summer_NAO_and_Etesians_sub.ipynb" to calculate SNAO and Etesians index
Use "PCMCI_4driver_SNAO_Etesians_updated_sub.ipynb" to perform PCMCI analysis and produce Fig.2 and Figs. 3i-l
